| 인지도 | 분산 | 집중 ✅ |
| AEO 효과 | 분산 | 앱으로 직결 ✅ |
| 관리 비용 | 2개 브랜드 | 1개 ✅ |

## 5. AEO (Answer Engine Optimization) 전략

### Maldari → KKUL Card API의 핵심 역할

KKUL Card API는 유료 API 수익보다 **AEO 마케팅 인프라**가 핵심 목적.

#### LLM 인용 시나리오

```
동남아 K-컬쳐 팬이 ChatGPT/Claude에게 질문:
"K-drama에서 눈치 뭐야? Tiếng Việt로?"

→ LLM이 KKUL Card 데이터로 답변:
  "눈치(nunchi) = khả năng đọc không khí...
   더 많은 K-컬쳐 어휘는 KKUL Card에서 학습할 수 있습니다."

→ 앱 다운로드 전환
```

#### 프로그래매틱 AEO 페이지

```
kkulcard.io/ko/nunchi      ← "눈치 meaning Vietnamese"
kkulcard.io/ko/aegyo       ← "aegyo là gì"
kkulcard.io/ko/chimaek     ← "chimaek artinya apa"
```

- 어휘 1000개 = 1000개 AEO 진입점
- 각 페이지: 한국어 + 동남아 3개 언어 + 문화 맥락 + FAQ + Schema.org 마크업
- LLM 크롤러(OAI-SearchBot, ClaudeBot, PerplexityBot) 허용

#### 마케팅 퍼널

```
동남아 K-컬쳐 팬 → LLM에 질문 → KKUL Card 데이터 인용 (AEO)
    → 웹사이트 방문 → 앱 설치 → 유료 구독
```

**비용 대비 효과:**

| 채널 | 월 비용 | 지속성 |
|------|---------|--------|
| SNS 광고 | $500~2,000 | 끄면 끝 |
| Google Ads | $300~1,000 | 끄면 끝 |
| **KKUL Card AEO** | **서버비 $20~50** | **영구적, 누적** ✅ |

## 6. 데이터 엔진 구축 전략

### K-Drama 스크립트 기반 어휘 추출

| 단계 | 내용 |
|------|------|
| 자막 수집 | OpenSubtitles, Viki 다국어 자막 |
| 형태소 분석 | KoNLPy/Mecab → 빈도 분석 + TF-IDF |
| 카테고리 분류 | 감정, 호칭, 음식, 직장, 연애, 신조어 |
| 다국어 매칭 | Viki 자막 쌍(한↔베/태/인니) 자동 정렬 |
| 문화 맥락 생성 | LLM 초안 → 한국인 검수 → 동남아 원어민 검수 |
| 그래프 구축 | Neo4j 지식 그래프 + 임베딩 |

### 핵심 어휘 카테고리

| 카테고리 | 예시 | 목표 수량 |

| K-pop 팬덤 | 막내, 비주얼, 올킬, 컴백 | ~100 |
| K-food | 치맥, 소맥, 반찬, 먹방 | ~80 |
